## IsLandToken 0.3.3

- 更新下载按已接收字节显示真实进度和百分比；校验与安装准备阶段显示明确的处理状态。
- 下载阶段增加“取消更新”按钮；取消会停止网络任务或 GitHub CLI 下载、清理临时文件，并可重新下载。
- 进入校验和应用替换阶段后自动关闭取消能力，避免中断已开始的安装事务。
- 更新窗口改为普通窗口层级，可手动最小化，不再始终置顶、自动最小化或强制抢回焦点。
- 修复下载任务创建前取消可能导致网络会话异常的问题，并增加预取消与进度边界回归测试。
- 将应用内更新源切换到独立仓库 `taishanrou/Islandtoken`。

本版本会以同一构建同时发布到旧仓库和独立仓库，确保 0.3.1、0.3.2 用户均可通过应用内“下载并安装”升级；后续版本由独立仓库提供。已有设置保持不变。

当前产物为 Apple Silicon、macOS 14+；采用本地临时签名，未进行 Apple 开发者签名或公证。
