## IsLandToken 0.3.0

- 灵动岛展开宽度按模型与详情内容自适应，去除模型右侧多余空白，并限制内容不越出边框。
- 最小态左侧模式仅增加左侧 5pt，右侧模式仅增加右侧 5pt；两侧模式、悬停放大和详情展开均不增加边距。
- 优化单击、双击和移出收缩：单击立即显示详情，双击刷新不再延迟首击，鼠标移出后自动收起。
- 增加单实例保护，同一时间只运行一个 IsLandToken。
- 发现新版本时自动提示；点击“下载并安装”后自动下载 DMG 与校验文件，验证版本、架构和签名后替换应用并重启，启动失败时自动回滚。

从 0.2.x 升级到 0.3.0 仍需手动安装一次；安装 0.3.0 后，后续版本可直接在应用内自动更新。已有设置保持不变。

当前产物为 Apple Silicon、macOS 14+；采用本地临时签名，未进行 Apple 开发者签名或公证。
